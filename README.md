### Status
Uma landing page moderna e elegante para barbearias, desenvolvida como um projeto de portfólio por **Isaque Santos**. Este projeto demonstra habilidades em desenvolvimento front-end com tecnologias de ponta e está disponível para venda e customização.

---

### 📄 Sobre o Projeto
O **BarberLab** é uma solução completa de landing page para barbearias que buscam uma presença online profissional e atraente. O design é focado na experiência do usuário, com seções bem definidas para agendamento, serviços, preços, história da empresa, loja de produtos e muito mais.

Este projeto foi criado como uma peça de portfólio para exibir competências em desenvolvimento web moderno, mas foi construído com a flexibilidade de ser adaptado e vendido para qualquer negócio no ramo da barbearia.

---

### 🚀 Principais Funcionalidades
- **🎨 Design Moderno e Responsivo:** Experiência de usuário impecável em desktops, tablets e celulares.
- **⚡ Performance Otimizada:** Construído com Vite e usando técnicas como *lazy loading* para um carregamento rápido e eficiente.
- **🗓️ Agendamento via WhatsApp:** Uma seção de agendamento intuitiva que integra diretamente com o WhatsApp para facilitar a marcação de horários.
- **🛠️ Seção de Serviços Detalhada:** Apresente os serviços oferecidos com imagens e descrições claras.
- **💰 Tabela de Preços Flexível:** Exiba seus pacotes de serviços de forma organizada e atraente.
- **🛍️ Página de Loja:** Uma área dedicada para exibir e vender produtos premium.
- **👥 Página de Carreiras:** Atraia novos talentos com uma página "Junte-se à Equipe" com formulário de candidatura via WhatsApp.
- **📚 Múltiplas Páginas Informativas:** Inclui páginas como "Nossa História", "Ajuda", "Atacado" e "Central de Aprendizagem".
- **👨‍💻 Componentização com shadcn/ui:** Utilização de componentes de alta qualidade, acessíveis e customizáveis.

---

### 🛠️ Tecnologias Utilizadas
- **Framework:** React (v18)
- **Linguagem:** TypeScript
- **Build Tool:** Vite
- **Estilização:** Tailwind CSS
- **Componentes UI:** shadcn/ui
- **Roteamento:** React Router (`react-router-dom`)
- **Ícones:** Lucide React
- **Notificações:** Sonner

### ⚙️ Como Executar Localmente
Siga os passos abaixo para rodar o projeto em seu ambiente de desenvolvimento.

**Pré-requisitos:**
- Node.js (versão 18 ou superior)
- npm ou yarn

**Passos:**

1.  **Clone o repositório:**
    ```sh
    git clone https://github.com/IsaqueCodeX/barberlab.git
    ```

2.  **Navegue até o diretório do projeto:**
    ```sh
    cd barberlab
    ```

3.  **Instale as dependências:**
    ```sh
    npm install
    ```

4.  **Inicie o servidor de desenvolvimento:**
    ```sh
    npm run dev
    ```

5.  Abra seu navegador e acesse `http://localhost:8080` para ver a aplicação.
